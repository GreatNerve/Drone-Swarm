# AGENTS

Rules for every agent session in this repo. Product details live in `CONTEXT.md` and `docs/`.

## Before any search or edit

1. Read `CONTEXT.md` (glossary) and `docs/README.md` (module index).
2. If the user just ran a demo and reports a visual/control issue, read `no-push/runs/` (last 3 JSON files) before searching code.
3. Graphify query only for an architecture / "where is X" question that is not already answered in this chat or in open files. Do not query on every turn.
4. Rebuild (`--update`, `--cluster-only`, full `/graphify`) only when the user asks, or when a local query missed because the graph is stale. Local AST only. Gemini only if that local extract fails.
5. Dump long extracts, OCR, PDFs-as-md, and throwaway scripts into `no-push/`. Never search or re-ingest those files if an extract already exists there.

## Build like this

- Shortest working diff. Reuse existing helpers. No speculative files or "for later" scaffolding.
- No decorative comments. Comment only non-obvious constraints (`ponytail:` for deliberate shortcuts).
- Handle loading and error states at trust boundaries (UI, IO, APIs).
- One module → one doc under `docs/modules/<name>.md` when that module exists.

## Git

- Never add `Co-authored-by`, `Generated by`, `Made with`, or any AI/tool author line.
- Never stage `no-push/`.
- Do not change git config. Commit only when the user asks.

## Docs vs code

- `CONTEXT.md`: terms and aliases only.
- `docs/`: architecture, modules, conventions, ADRs.
- Code: implementation. Do not copy architecture essays into comments.
